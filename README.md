## Test locally

Extract the ZIP and double-click `index.html`. Keep the `assets` folder beside the HTML, CSS, and JavaScript files.

## Upload to your existing GitHub repository

1. Go to https://github.com/sarva-sarvendhra/sarvendhra-portfolio
2. Choose **Add file → Upload files**.
3. Open the extracted folder and drag **all of its contents** (`index.html`, `styles.css`, `script.js`, `README.md`, and the complete `assets` folder) onto the upload area. Do not upload the ZIP itself or create an extra nested portfolio folder in the repository.
4. Choose **Commit changes** after the upload finishes.
5. Open **Settings → Pages → Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
6. Once GitHub finishes deploying, visit https://sarva-sarvendhra.github.io/sarvendhra-portfolio/

The workbook link is on the Langley Flow interactive masterplan section and opens the PDF in a new tab.
